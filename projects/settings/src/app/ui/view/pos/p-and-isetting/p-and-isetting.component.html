Paystack Payment Account Setup

Step 1: Select Branch for API Key Configuration 🔑
Step 2: Sign Up & Verify Business (KYC)

👉 Sign up on Paystack

  • Complete your profile and submit **KYC/Compliance** documents (ID, CAC, etc.).
  • Verification is mandatory to get **Live API Keys**.
Step 3: Add Settlement Bank Account
  • Go to **Settings → Payouts / Bank Accounts**.
  • Add the bank account where you want payments to be deposited.
Step 4: Get Your Live API Keys
  • In the Paystack dashboard, go to **Settings → API Keys & Webhooks**.
  • Copy your **Live Public Key** and **Live Secret Key**.
  • ⚠️ **Do NOT** paste the Secret Key here. Only the Public Key is needed.
Step 5: Paste Live Public Key Into This ERP

Paste your **Live Public Key** below for the selected branch. We handle the Secret Key securely.

Note:

If you need to update the **Live Secret Key**, please contact support as it is stored securely and not edited via this screen.
