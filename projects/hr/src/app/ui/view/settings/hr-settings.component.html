Hikvision Integration Config

Configure the DS-K1T321 (and compatible) terminals to push attendance events to OptimaX automatically.

Callback Endpoint

Enter this URL in the Hikvision device web interface under Configuration → Network → Advanced Settings → Linked Network Application → Subscribing Host Address.

{{ hikCallbackUrl }}
Replace <YOUR_TOKEN> with the value of the HIKVISION_CALLBACK_TOKEN environment variable set on the HR service server. This token is the shared secret that authenticates the device push. Keep it out of source control.

Environment Variable

Set the following on the HR microservice host (production):

HIKVISION_CALLBACK_TOKEN=your-strong-secret-here

Default fallback is hik-cb-prod-change-me — change this before going live.

Device Configuration Steps

  1. Open a browser and navigate to the device IP (e.g. http://192.168.1.100).
  2. Log in with admin credentials (default: admin / 12345 — change immediately).
  3. Go to Configuration → Network → Advanced Settings → Linked Network Application.
  4. Set Subscribing Host Address to the callback URL above (with your token).
  5. Set Subscribing Host Port to 443.
  6. Enable HTTPS and set the event subscription to include Access Control Events.
  7. Save and reboot the device.
  8. Register the device in OptimaX using the Biometric Devices settings panel (IP address must match).
  9. Enroll employee fingerprints / faces in the Personnel → Biometric Enrollment module.
