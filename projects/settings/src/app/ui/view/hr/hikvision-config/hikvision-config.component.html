Hikvision Integration Config

Configure the DS-K1T321 (and compatible) terminals to push attendance events to OptimaX automatically.

Callback Endpoint URL

Enter this URL in the Hikvision device web interface under Configuration → Network → Advanced Settings → Linked Network Application → Subscribing Host Address.

{{ callbackUrl }}

Replace <YOUR_TOKEN> with the value of the HIKVISION_CALLBACK_TOKEN environment variable set on the HR service host.

Environment Variable (Production Server)
HIKVISION_CALLBACK_TOKEN=your-strong-secret-here

Default fallback is hik-cb-prod-change-me — change this before going live.

Device Configuration Steps
  1. Open a browser and navigate to the device IP (e.g. http://192.168.1.100).
  2. Log in with admin credentials (default: admin / 12345 — change on first login).
  3. Go to Configuration → Network → Advanced Settings → Linked Network Application.
  4. Set Subscribing Host Address to the callback URL above (with your token substituted).
  5. Set Subscribing Host Port to 443 (HTTPS).
  6. Enable HTTPS and subscribe to Access Control Events.
  7. Save and reboot the device.
  8. Register the device in HR Settings → Biometric Devices (IP address must match).
  9. Enroll employee fingerprints / faces in Personnel → Biometric Enrollment.
