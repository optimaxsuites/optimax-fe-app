How it works

One task can carry several delivery items from start to finish.

  • Create the parent task and add nested sub tasks such as UI, backend linking, or vendor actions.
  • Assign each sub task to a real staff owner, set dates, and mark dependencies.
  • Share the parent plan with a supervisor, capture feedback, then keep progress and review history in one place.
