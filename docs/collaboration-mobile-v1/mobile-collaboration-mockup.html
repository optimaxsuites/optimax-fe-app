Mobile Collaboration Concept

Drawer-first chat and feed for narrow screens.

The desktop visual language stays intact, but the mobile experience becomes thumb-friendly, message-first, and fast to navigate between feed, channels, DMs, and threads.

Principle Keep the current web identity. Compress structure, not functionality.
Navigation Sidebar becomes a full-height drawer with unread counters, search, channels, and DMs.
Priority Compose, reply, react, and jump to messages without losing context.

Implementation Direction

  • The left desktop sidebar becomes a slide-in drawer under `920px`, with a persistent menu button in the top bar.
  • The feed rail and thread rail collapse into stacked cards or bottom sheets so users never lose the message composer.
  • Unread counters remain visible on active items until the user actually opens the thread or conversation.
  • Composers stay pinned near the bottom with enough room for attachments, emoji, mentions, and reply context.
  • Post cards, chat bubbles, and thread cards use the same desktop brand language, only denser and more touch-friendly.
