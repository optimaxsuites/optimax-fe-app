OptimaX Suites Prototype V2

Phone and Tablet Native App Review

This revision re-centers the prototype on the actual OptimaX frontend already in this repo: Dashboard, Expenses, HR Attendance, and Collaboration. The boards intentionally use Naira values, OptimaX module labels, and non-generic employee identities from the frontend HR samples.

Scope Dashboard, Expenses, HR Attendance, Collaboration
Devices Phones and tablets in every concept board
Recommended Concept 1 as base system direction

What Changed

  • Shifted away from generic ERP patterns toward the real OptimaX module structure
  • Added tablet layouts alongside phone layouts
  • Used Naira defaults across the financial screens
  • Included Collaboration Workspace and Enterprise Feed as first-class modules

Data Notes

  • Names are drawn from frontend HR sample employee data already embedded in the app
  • The configured live HR `findAllEmployee` endpoint returned `401 Unauthorized` from this shell
  • Because of that, this package does not claim live tenant employee fidelity
  • It does preserve OptimaX naming and app-language fidelity

PRD source: docs/native-app-prototype-v2/prd.md

Concept 1

OptimaX Command Center

The strongest all-around suites narrative. This concept best communicates one unified platform spanning dashboarding, expense control, attendance, and collaboration.

Best Use Primary design direction for the overall product family
Strengths Best cross-module coherence, strongest tablet-plus-phone story, closest “one suite” message
Tradeoff Slightly less guided in task progression than Concept 2
Concept 2

OptimaX Workflow Navigator

The clearest process-led concept. Expense actions, approvals, attendance handling, and collaboration flow feel highly intentional and operationally guided.

Best Use Staff-facing workflows and adoption-focused first release
Strengths Clearest next steps, strongest task flow, very understandable across teams
Tradeoff Slightly less premium and less executive-heavy than Concepts 1 and 3
Concept 3

OptimaX Executive Grid

The most analytical and structured board. It is strongest where leadership, managers, and operations users need denser information and faster scanability.

Best Use Executive and manager-facing views, especially dashboard and approvals
Strengths Best data density, strongest analytical tone, clear operational monitoring
Tradeoff Heavier feel for casual users and slightly less warm than Concept 1
