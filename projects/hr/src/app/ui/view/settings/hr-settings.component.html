Import Projects from Odoo

Connect to your Odoo instance to pull tasks and projects into the OptimaX Task Board.

Odoo Project Integration
Supported: Odoo 15, 16, 17 (Community & Enterprise)
What gets imported:
  • Project tasks → Task Board cards
  • Task stages → Kanban status (To Do / In Progress / Done)
  • Assignees → matched to OptimaX employees by name
  • Deadlines → due dates
  • Sub-tasks → OptimaX subtask items
  • Tags → task tags
Alternative: CSV Export from Odoo

In Odoo: Project → Tasks → Action → Export. Select these columns:

{{ col }}

Then use the Batch Import tab on the Task Board to paste the exported data.

Odoo Connection Details

Your credentials are used only to fetch data — they are not stored on the server.

Note: OptimaX connects to Odoo via its XML-RPC API (port 8069 by default). Make sure your Odoo instance is accessible from the network. For cloud-hosted Odoo, use your subdomain URL. Generate an API Key in Odoo under Settings → Technical → Allowed API Keys for better security.
