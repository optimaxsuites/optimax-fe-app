Import Projects from Odoo

Connect to your Odoo instance to pull tasks and projects into the OptimaX Task Board.

Odoo Project Integration
Supported: Odoo 15, 16, 17 (Community & Enterprise)
What gets imported:
  • Project tasks → Task Board cards
  • Task stages → Kanban status (To Do / In Progress / Done)
  • Assignees → matched to OptimaX employees by name
  • Deadlines → due dates
  • Sub-tasks → OptimaX subtask items
  • Tags → task tags
Alternative: CSV Export from Odoo
